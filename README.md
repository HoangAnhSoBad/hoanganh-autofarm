# HoangAnh Auto Farm · v3.5.0

Auto farm cho [PokéSurvivor](https://pokesurvivor.com/)
và [Doofcraft](https://pokesurvivor.doofcraft.com/).

## Tải và cài đặt

- **Máy tính:** [⬇ Tải ZIP v3.5.0](https://github.com/HoangAnhSoBad/hoanganh-autofarm/releases/download/v3.5.0/hoanganh-autofarm-resource-v3.5.0.zip)
- **Android:** [⬇ Cài/cập nhật userscript](https://raw.githubusercontent.com/HoangAnhSoBad/hoanganh-autofarm/main/hoanganh-autofarm-mobile.user.js)
- **Gói Mobile:** [⬇ Tải ZIP v3.5.0](https://github.com/HoangAnhSoBad/hoanganh-autofarm/releases/download/v3.5.0/hoanganh-autofarm-mobile-v3.5.0.zip)

**Máy tính:** Giải nén ZIP → mở `chrome://extensions` →
bật Developer mode → Load unpacked → chọn thư mục chứa `manifest.json`.
Tắt bản cũ rồi tải lại game.

**Android:** Dùng Firefox và Tampermonkey, mở link userscript bên trên
và xác nhận cài/cập nhật phiên bản 3.5.0.
Nếu trình duyệt chỉ hiện mã, dùng mục cài từ URL trong Tampermonkey.
Tải lại game sau khi cập nhật. Bản Android vẫn đang thử nghiệm.

## Thiết lập dùng TM

Trong Build:
1. Bật “Dùng TM đã có” và “Chuẩn bị TM trước lượt”.
2. Chọn “Ưu tiên build dùng TM đã có”.
3. Lưu cấu hình, mở trang nâng cấp đúng Pokémon rồi bắt đầu farm.

Tool chỉ xét các build có trong dữ liệu tham khảo;
không bảo đảm mọi TM đều có build tương ứng.
